# Mode

> Mode is a collaborative business intelligence and analytics platform that unites data and business teams around a single analytical workflow — ad hoc SQL, Python/R notebooks, interactive dashboards, self-serve reporting, and custom data apps on top of connected data warehouses. Mode (acquired by ThoughtSpot in 2023) exposes a REST API for programmatic management of workspaces, users, data sources, reports, queries, charts, datasets, definitions, exports, schedules, and subscriptions. Auth is HTTP Basic with an API token + secret; responses are HAL+JSON; access requires a paid Mode Business workspace.

## APIs
- [Mode API reference](https://mode.com/developer/api-reference/introduction/): REST API, base URL https://app.mode.com/api
- [Authentication](https://mode.com/developer/api-reference/authentication/): HTTP Basic with workspace/personal API token + secret
- [Error codes](https://mode.com/developer/api-reference/error-codes/): 400/401/403/404 with { id, message } envelope
- [API Cookbook](https://mode.com/developer/api-cookbook/introduction/): automation workflow recipes
